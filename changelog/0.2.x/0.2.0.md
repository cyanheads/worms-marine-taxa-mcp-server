# 0.2.0 — 2026-10-28

## Added

- **`worms-marine-taxa-guide`** agent skill, served over MCP as the resource `skill://worms-marine-taxa-guide/SKILL.md` (resource template `skill://{+path}`) through `createApp({ skills: 'skills' })`, and shipped in the npm package, Docker image, and `.mcpb`. It covers checklist cleaning, common names, alien-range questions, trait provenance, original descriptions, and ID reconciliation.

## Changed

- **`marineOnly`** on `worms_resolve_taxon` and `worms_get_classification`, the `worms_resolve_taxon` description, and the server instructions now say the default keeps taxa WoRMS flags marine or brackish (brackish-but-not-marine taxa such as *Dreissena polymorpha* match). The filter's behavior is unchanged.
- **`@cyanheads/mcp-ts-core`** ^0.13.16 → ^0.13.18: skills served through `createApp({ skills })` (0.13.18, [cyanheads/mcp-ts-core#789](https://github.com/cyanheads/mcp-ts-core/issues/789)); the HTTP transport no longer retains memory per request, which grew a long-running server's heap under Bun, the published image's runtime (0.13.17, [cyanheads/mcp-ts-core#786](https://github.com/cyanheads/mcp-ts-core/issues/786)); MCP SDK 2.4.0 (0.13.17).
- **Packaging** gains the Agent Plugins root `plugin.json` and `mcp.json`; the `.mcpb` bundle now leaves out repo-local root paths (`src/`, `changelog/`, `CLAUDE.md`, `AGENTS.md`, `.github/`, and similar) and the framework's build-only files.
- **Development tooling** resyncs `framework-skills/` and `scripts/` (the bundle cleaner's agent-doc matcher keeps the MCP SDK's runtime `dist/ext/skills/` modules and has a regression test), condenses the README getting-started section, and sets `minimumReleaseAge` to 1 day (was 3).
