# 0.2.1 — 2026-11-21

## Added

- **`worms_get_classification`** includes child authorship and accepted-name links when WoRMS supplies them (#25).
- **`worms_resolve_taxon`** includes the kingdom in scientific and common-name matches when supplied (#26).
- **`worms_crosswalk_id`** reports whether the forward AphiaID exists, identifies accepted or preferred AphiaIDs, and points successful identifier types with zero results to synonym lookups (#27).
- **`worms_resolve_taxon`** accepts `matchAuthority: true` for strict fuzzy matching. If strict matching misses, retry with `matchAuthority: false` (#28).

## Changed

- Updated the WoRMS agent guide, framework scripts and skills, and bundle cleanup. The MCPB keeps SDK runtime modules while removing dependency agent docs.

## Fixed

- **`worms_get_taxon`** gives a bibliography request one attempt of up to 40 seconds within the shared 45-second call deadline (#22).
- **`worms_get_traits` and `worms_get_distributions`** report `found: false` for a missing record, `true` for a registered taxon, and `null` when an optional status read fails (#23).
- **`worms_get_classification`** suggests relaxing active filters or returning to the first upstream page when WoRMS returns an empty children page (#24).
