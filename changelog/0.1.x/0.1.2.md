# 0.1.2 — 2026-10-21

## Added

- **`worms_get_distributions` `includeSynonyms`** combines the accepted taxon's records with its synonyms', 10 synonyms per window; `synonymOffset` selects the window, rows carry `sourceAphiaId`, and `synonymUnion` reports `nextSynonymOffset` and `failedSynonyms` ([#4](https://github.com/cyanheads/worms-marine-taxa-mcp-server/issues/4)).
- **Unaccepted-ID notice** on `worms_get_distributions`, `worms_get_traits`, and `worms_get_classification` names `validAphiaId` when the submitted ID is not accepted; a failed status read adds `statusError` instead ([#4](https://github.com/cyanheads/worms-marine-taxa-mcp-server/issues/4)). Each of the three now makes one extra paced status read per call.
- **`worms_get_taxon` `includeSources`** returns the taxon's `sources` rows (original description, basis of record) for a single ID, paged locally with `sourceOffset` and `nextSourceOffset`; a failed read adds `sourcesError` ([#6](https://github.com/cyanheads/worms-marine-taxa-mcp-server/issues/6)).
- **`worms_resolve_taxon` `vernacularMatch`** (`exact` default, `contains`) enables substring vernacular search ([#7](https://github.com/cyanheads/worms-marine-taxa-mcp-server/issues/7)).
- **`worms_get_traits` `measurementType`** filters the attribute tree to matching nodes, their subtrees, and their ancestors; `unfilteredCount` reports the unfiltered total ([#10](https://github.com/cyanheads/worms-marine-taxa-mcp-server/issues/10)).
- **`worms_list_reference`** `statuses` cover the live taxonomic statuses with a `group` field, and a new `distribution_terms` topic lists the observed `establishmentMeans`, `invasiveness`, and `occurrence` filter values ([#9](https://github.com/cyanheads/worms-marine-taxa-mcp-server/issues/9)).

## Changed

- **`content[]` text** renders as a nested CommonMark list of relative keys instead of one path-prefixed line per node, so pages carry more items under the 24,000-byte budget; `structuredContent` is unchanged ([#5](https://github.com/cyanheads/worms-marine-taxa-mcp-server/issues/5)).
- **`worms_resolve_taxon` name batches** start at `inputOffset`, so successive pages stop re-fetching the same 50 names ([#5](https://github.com/cyanheads/worms-marine-taxa-mcp-server/issues/5)).
- **Recovery hints** for timeouts, outages, and oversized responses name a step for the tool that failed, on thrown errors and item errors alike ([#12](https://github.com/cyanheads/worms-marine-taxa-mcp-server/issues/12), [#13](https://github.com/cyanheads/worms-marine-taxa-mcp-server/issues/13)).
- **Package description and keywords** name WoRMS marine species in npm, registry, plugin, bundle, and image metadata.

## Fixed

- **`worms_resolve_taxon` miss guidance** suggests `extantOnly: false` while the extant filter is on, and the `offset` description says it applies to vernacular search only ([#8](https://github.com/cyanheads/worms-marine-taxa-mcp-server/issues/8)).
- **`worms_resolve_taxon` 50-match notice** appears only on pages that hold such a group and names its `inputIndex` ([#11](https://github.com/cyanheads/worms-marine-taxa-mcp-server/issues/11)).
- **Empty-result notices** in `worms_get_synonyms`, `worms_get_classification`, `worms_resolve_taxon`, and `worms_get_distributions` no longer recommend the call that returned nothing ([#13](https://github.com/cyanheads/worms-marine-taxa-mcp-server/issues/13)).
