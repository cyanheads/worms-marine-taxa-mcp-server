# 0.1.1 — 2026-10-20

## Added

- **Eight read-only tools** resolve scientific and common names, fetch taxa, classifications, synonyms, distributions and traits, crosswalk nine identifier systems, and inspect reference vocabularies.
- **Scientific evidence** preserves accepted-name links, citations, unknown values, source ordering, and trait hierarchy across matching readable and structured output.

## Changed

- **Read responses** target 24,000 bytes with whole-item continuation, original batch positions, and global tree indices; indivisible oversized items remain intact with explicit size disclosure ([#2](https://github.com/cyanheads/worms-marine-taxa-mcp-server/issues/2)).
- **Build and packaging** use native TypeScript ESM output, Knip dependency checks, client install metadata, and portable MCPB exclusions.

## Security

- **Path selectors** reject exact dot-only vernacular names and reverse external IDs before fetching ([#1](https://github.com/cyanheads/worms-marine-taxa-mcp-server/issues/1)).
