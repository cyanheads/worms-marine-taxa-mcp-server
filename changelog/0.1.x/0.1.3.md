# 0.1.3 — 2026-10-24

## Changed

- **Checklist continuation** accepts nonempty scientific-name and AphiaID lists without a total-input ceiling; each call retains its 50-position window, response budget, and original continuation coordinates. [#18](https://github.com/cyanheads/worms-marine-taxa-mcp-server/issues/18)
- **`worms_get_taxon.sourceUse`** filters complete bibliographies by case-insensitive whole use before pagination; successful reads report selected counts and, with a filter, unfiltered counts. [#19](https://github.com/cyanheads/worms-marine-taxa-mcp-server/issues/19)
- **Hosted configuration** advertises the public Streamable HTTP endpoint and documents Claude Code, Cline, and Cursor connection examples.
- **Development tooling** refreshes framework guidance, attributes audit advisories to the installed direct dependency, and uses Bun 1.4.4 for development and container images.

## Fixed

- **AphiaID selectors** accept canonical WoRMS LSIDs and decimal strings while preserving numeric outputs and existing transport repairs; invalid strings provide crosswalk or scientific-name recovery guidance. [#16](https://github.com/cyanheads/worms-marine-taxa-mcp-server/issues/16)
- **Distribution `recordStatus`** normalizes case and surrounding whitespace before filtering and echoes the canonical lowercase code. [#15](https://github.com/cyanheads/worms-marine-taxa-mcp-server/issues/15)
- **Evidence notices** identify accepted alternative representations and their preferred AphiaIDs without mislabeling the submitted name as unaccepted. [#17](https://github.com/cyanheads/worms-marine-taxa-mcp-server/issues/17)
